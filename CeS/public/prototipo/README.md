# Protótipo convertido para HTML e CSS

As telas nesta pasta foram convertidas dos componentes e páginas Vue presentes no arquivo `nucleo-marcus-jussier.zip`. Abra `index.html` para navegar pelo protótipo.

O conteúdo está dividido em telas públicas e administrativas. O CSS compartilhado está em `style.css`. Como a conversão solicitada é apenas para HTML e CSS, os dados são exemplos estáticos e elementos de busca, filtros, autenticação e gravação não executam lógica.
